Tolong buatkan halaman dengan judul "Apa itu Table?"
base knowledge:

1.  Table adalah salah satu komponen dalam modul Data di Phoenix.
2.  Table dapat menyimpan data secara kompleks. Sifat data ini dapat digunakan untuk menyimpan data yang transaksional maupun generik. Table dapat memiliki beberapa [[Docs/Tipe Data/Column]] yang masing-masing memiliki format yang berbeda, dan memiliki [[Docs/Tipe Data/Row]] yang masing-masing memiliki [[Docs/Tipe Data/TableData]] sesuai kolom yang tersedia. [[Docs/Tipe Data/Expression]] dapat berfungsi oleh komponen ini secara langsung.
3.  Isi Row ketika Table baru dibuat masih kosong.
4.  Gambar saat membuat Table bisa dilihat pada lampiran.
5.  Kolom tambahan dalam halaman kerja Table adalah ID diawal, dan Action diakhir.
6.  Alias dalam kolom harus dipilih salah satu, alias yang dipilih akan tampil di field dengan format Row. (formatnya "ID - Alias Value"
7.  Contoh Halaman kerja Table bisa dilihat dilampiran
8.  Merge, Publish, Event detailnya akan dijelaskan dihalaman lain.
