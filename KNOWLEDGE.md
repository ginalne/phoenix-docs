Setiap Pro akses dimulai dari _origin root_, Workspace pertama kali dibuat adalah Origin. Workspace bisa dipindahkan kemana saja, tapi harus ada satu workspace di level _origin root_. Workspace baru di folder dalam akan jadi folder *root*, tiga tingkat akses (Comp. Access, Data Access, Function Access), makna Visible = disallow, jenis data per komponen (Row untuk Table, Timeline Data untuk Timeline), serta navbar workspace hanya Edit dan Refresh. Alasannya, fakta ini akan dipakai lagi di halaman komponen lain.
