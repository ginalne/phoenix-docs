# URL
format dalam [[Docs/Datatype/String]] yang memberikan pengalaman input yang aman untuk pengisian URL, karena secara default pengisi harus dengan benar memasukan data sesuai dengan format URL, yaitu kode metode (seperti https://) dan diikuti dengan domain dan parameternya.

Format ini juga membantu Anda untuk membuka halaman website dengan lebih mudah.
