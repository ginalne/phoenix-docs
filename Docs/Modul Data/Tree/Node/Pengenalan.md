# Tree Node

Tree Node (atau [[Docs/Tipe Data/Node]] dalam konteks Tree) adalah satu unit data pada Tree yang memiliki atribut [[^field|Order]], [[^field|Name]]. Unit data ini juga dapat digunakan dalam _field_ sebagai [[Tipe Data/Pengenalan|Tipe Data]].

Berikut adalah aksi yang bisa dilakukan untuk mengelolanya dalam halaman kerja Tree :

1. [[Docs/Modul Data/Tree/Node/Menambahkan]]
2. [[Docs/Modul Data/Tree/Node/Mengubah Nama]]
3. [[Docs/Modul Data/Tree/Node/Mengubah Urutan]]
4. [[Docs/Modul Data/Tree/Node/Menghapus]]
5. [[Docs/Modul Data/Tree/Node/Melihat Detail]]
6. [[Docs/Modul Data/Tree/Node/Mengatur Tampilan]]
7. [[Docs/Modul Data/Tree/Node/Mengekspor]]
8. [[Docs/Modul Data/Tree/Node/Mengimpor]]

## Menu Konteks Node

![[Docs/Modul Data/Tree/Node/tree-context.png]]
Klik kanan pada Node untuk membuka menu konteks berikut.

| Menu | Fungsi |
| --- | --- |
| [[^field/edit|Edit]] | Mengubah Node. Lihat [[Docs/Modul Data/Tree/Node/Mengubah Urutan]] atau [[Docs/Modul Data/Tree/Node/Mengubah Nama]]. |
| [[^field/eye|Detail]] | Melihat detail Node. Lihat [[Docs/Modul Data/Tree/Node/Melihat Detail]]. |
| [[^field/collapse|Collapse]] atau [[^field/expand|Expand]] | Melipat atau memperluas keturunan selanjutnya dari Node. |
| [[^field|View]] | Membuka submenu pengaturan tampilan keturunan Node (lihat tabel di bawah). |
| [[^field/import|Import]] | Memasukkan data ke Node. Lihat [[Docs/Modul Data/Tree/Node/Mengimpor]]. |
| [[^field/export|Export]] | Mengeluarkan data dari Node. Lihat [[Docs/Modul Data/Tree/Node/Mengekspor]]. |
