# Menambahkan Table Row

1. Buka halaman kerja Table
2. Klik [[^button/add|Add Row]]
3. Isi data pada setiap Column
4. Klik [[^button/save|Save]]

Anda dapat klik [[^button/delete|Cancel]] untuk membatalkan penambahan Row.
