# TableData Merge

[[Docs/Tipe Data/TableData]] dalam [[Docs/Tipe Data/Row]] dapat diisi dengan bebas, namun dalam proses pengumpulan data, terkadang ada duplikasi input walaupun maksudnya sama. Sehingga diperlukan adanya proses Merge yang aman agar komponen yang telah terleasi dengan [[Docs/Tipe Data/Row]] yang sama.

## Melakukan Merge

Anda dapat mengaturnya melalui tombol [[button/merge|Merge]] dalam halaman kerja [[Docs/Modul Data/Enum/Apa itu Enum|Komponen Enum]].

![[Docs/Modul Data/Enum/enum-test.png|TableData Merge]]
Setelah Mode Merge aktif, maka Anda dapat memilih [[Docs/Tipe Data/TableData]] yang ingin digabungkan.

![[Docs/Modul Data/Enum/merge-select.png|TableData Merge Select]]
Lalu jika sudah selesai, selanjutnya klik tombol [[button/merge|Select Merge (*)]] (`*` adalah total [[Docs/Tipe Data/TableData]] yang akan dimerge).
