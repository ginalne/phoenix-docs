# Flow Activity

Panel Activity List menampilkan kolom berikut.

| Kolom | Penjelasan |
| --- | --- |
| **ID/Name** | Pengenal atau nama proses. |
| **Status/Type** | Status dan jenis proses. |
| **Start At** | Waktu proses dimulai. |
| **Updated At** | Waktu terakhir proses diperbarui. |
