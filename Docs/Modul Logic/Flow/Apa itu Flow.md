# Apa itu Flow?

_Flow_ merupakan salah satu komponen dalam modul [[Docs/Modul Logic/Pengenalan|Logic]] di Phoenix. 

Flow dapat digunakan untuk mengatur logika dan proses pengelolaan data dengan pendekatan aliran komposisi. Setiap blok yang dibangun dapat dihubungkan dan dimonitor agar setiap [[Docs/Event/Pengenalan|Event]] yang terikat dapat menghasilkan keluaran dan otomasi yang tepat.
