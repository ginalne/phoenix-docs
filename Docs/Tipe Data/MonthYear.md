# MonthYear

MonthYear adalah tipe data yang dapat menyimpan data bulan dan tahun.

## Penggunaan dalam Interface

MonthYear dapat digunakan secara interaktif dengan [[Docs/Modul Interface/Timeline/Apa itu Timeline|Timeline]]. Posisi tanggal dan waktu akan menjadi tanggal 1 (satu) dengan waktu sesuai GMT Anda.

## Format
>**note** Tipe data ini tidak memiliki format khusus.
