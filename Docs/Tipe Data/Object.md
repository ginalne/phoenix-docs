# Object

Object adalah [[Docs/Tipe Data/Pengenalan|Tipe Data]] yang menyimpan data obyek dengan format JSON (JavaScript Object Notation). Tipe Data ini juga sering digunakan dalam komponen [[Docs/Modul Logic/Flow/Apa itu Flow|Flow]] untuk proses interaksi dengan sistem lain melalui API.

## Format
>**note** Tipe data ini tidak memiliki format khusus.
