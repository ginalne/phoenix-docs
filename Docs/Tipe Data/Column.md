# Column

Column adalah tipe data khusus yang digunakan oleh komponen [[Docs/Modul Data/Table/Apa itu Table|Table]].

## Atribut

| Atribut | Penjelasan |
| --- | --- |
| [[^field|Name]] | Nama kolom |
| [[^field|Description]] | Deskripsi kolom |
| [[^field|Format]] | Format yang ditentukan untuk [[Docs/Tipe Data/TableData]] |
| [[^field|Alias]] | Status agar tampil dalam setiap pilihan [[Docs/Tipe Data/Row]] |
| [[^field|Table]] | Header dari Column|
| [[^field|Row]] | Daftar untuk mengisi  [[Docs/Tipe Data/TableData]] yang terikat|
| [[^field|TableData]] | Sel untuk mengisi nilai atau data|

## Format
>**note** Tipe data ini tidak memiliki format khusus.
