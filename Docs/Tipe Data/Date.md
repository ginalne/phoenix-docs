# Date

Date adalah tipe data yang dapat menyimpan data tanggal.

## Penggunaan dalam Interface

Date cukup baik dalam menyimpan data tanggal secara presisi, sehingga dapat digunakan secara interaktif dengan [[Docs/Modul Interface/Timeline/Apa itu Timeline|Timeline]]. Posisi waktu akan sesuai dengan GMT Anda.

## Format
>**note** Tipe data ini tidak memiliki format khusus.
