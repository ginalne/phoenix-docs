# Node

Node adalah tipe data khusus yang digunakan oleh komponen [[Docs/Modul Data/Tree/Apa itu Tree|Tree]].

## Atribut

| Atribut | Penjelasan |
| --- | --- |
| [[^field|Order]] | Urutan dalam saudara |
| [[^field|Name]] | Nama Node |
| [[^field|Tree]] | Header Node |
| [[^field|Parent]] | Node yang menjadi orangtua atau 1 tingkat diatas |
| [[^field|Children]] | Turunan dari Node |

## Format
>**note** Tipe data ini tidak memiliki format khusus.
