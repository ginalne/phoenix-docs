# Complex

Complex adalah [[Docs/Tipe Data/Pengenalan|Tipe Data]] yang memiliki atribut khusus untuk menyimpan informasi dengan menggunakan empat atribut bernilai angka berpresisi tinggi serta atribut inisial berbentuk teks. 

## Atribut

| Nama | Penjelasan |
| --- | --- |
| [[^field|x]] | Atribut pertama yang menyimpan nilai numerik. | 
| [[^field|y]] | Atribut kedua yang menyimpan nilai numerik, bernilai satu jika Format Data tidak menggunakannya | 
| [[^field|z]] | Atribut ketiga yang menyimpan nilai numerik, bernilai satu jika Format Data tidak menggunakannya | 
| [[^field|w]] | Atribut keempat yang menyimpan nilai numerik, bernilai satu jika Format Data tidak menggunakannya | 
| [[^field|uom]] | Atribut kelima yang menyimpan data inisial, _unit of measure_, tipe khusus atau kurs. Isinya tergantung Format Data yang digunakan |
