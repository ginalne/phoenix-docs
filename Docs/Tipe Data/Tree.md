# Tree

Tree adalah [[Docs/Tipe Data/Pengenalan|Tipe Data]] yang mewakili komponen [[Docs/Modul Data/Tree/Apa itu Tree|Tree]].

## Atribut

| Atribut | Penjelasan |
| --- | --- |
| [[^field|Name]] | Nama Enum. |
| [[^field|Description]] | Keterangan singkat tentang kegunaan Enum. |
| [[^field|Node]] | Satuan data hirarki atau struktural yang terelasi satu sama lain |
| [[^field|Merger Mode]] | Sifat Tree yang memiliki [[^field|Node]] dari Tree lainnya dan tidak memilikinya secara organik |

## Format
>**note** Tipe data ini tidak memiliki format khusus.
