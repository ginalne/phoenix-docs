# Year

Year adalah tipe data yang dapat menyimpan data tahun.

## Penggunaan dalam Interface

Year dapat digunakan secara interaktif dengan [[Docs/Modul Interface/Timeline/Apa itu Timeline|Timeline]]. Posisi tanggal dan waktu akan menjadi tanggal 1 (satu) januari dengan waktu sesuai GMT Anda.

## Format
>**note** Tipe data ini tidak memiliki format khusus.
