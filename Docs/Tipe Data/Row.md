# Row

Row adalah tipe data khusus yang digunakan oleh komponen [[Docs/Modul Data/Table/Apa itu Table|Table]].

## Atribut

| Atribut | Penjelasan |
| --- | --- |
| [[^field|Table]] | Header dari Row|
| [[^field|Column]] | Kolom untuk mengisi menentukan [[Docs/Format Data/Pengenalan|Format Data]] di tiap [[Docs/Tipe Data/TableData]] |
| [[^field|TableData]] | Sel untuk mengisi nilai atau data|

## Format
>**note** Tipe data ini tidak memiliki format khusus.
