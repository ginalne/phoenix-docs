# Styling Class

Ketika mengisi field [[^field|Class]], Anda diberikan kesempatan untuk mengatur desain antarmuka agar membantu informasi lebih interaktif dan cepat diserap oleh tim.

Phoenix secara _frontend_ menggunakan [Tailwind CSS](https://tailwindcss.com/docs) untuk mendesain antarmukanya, sehingga beberapa atribut tetap dapat digunakan selama nama kelas memang valid, akan tetapi tidak dijamin bahwa segala kelas yang disediakan Tailwind CSS bisa digunakan oleh Phoenix. Sehingga untuk templat yang familiar digunakan untuk desain antarmuka bisa menggunakan kelas khusus yang disediakan oleh Phoenix.
