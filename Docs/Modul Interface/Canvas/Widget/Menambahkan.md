# Menambahkan Widget

![[Docs/Modul Interface/Canvas/Widget/add-widget-canvas.png]]
1. Aktifkan [[^mode/edit|Edit]].
2. Fokus dengan klik kiri [[Docs/Modul Interface/Canvas/Layout]] yang akan diisi widget baru. Abaikan langkah ini jika Canvas masih kosong.
3. Klik [[^field|Type something here to add...]] pada header atau halaman.
4. Pilih [[Docs/Modul Interface/Canvas/Widget/Pengenalan|Widget]] pada dropdown yang muncul, atau ketik untuk mencari [[Docs/Modul Interface/Canvas/Widget/Pengenalan|Widget]] yang diinginkan.

>**success** Widget Table berhasil ditambahkan
> Widget tampil di Canvas. Klik kiri widget untuk memfokuskan dan menampilkan panel konfigurasi. Selengkapnya lihat [[Docs/Modul Interface/Canvas/Widget/Mengonfigurasi|Konfigurasi Widget]]
