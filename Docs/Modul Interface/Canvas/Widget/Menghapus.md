# Menghapus Widget

Menghapus widget dapat dilakukan dengan 2 cara, yaitu melalui toolbar dan menu konteks.

## Melalui Header Toolbar

1. Aktifkan [[#Mode View dan Edit Mode|Edit Mode]]
2. Klik kiri Widget yang akan dihapus
3. Klik [[^button/delete|Remove]] pada [[Docs/Modul Interface/Canvas/Widget/Mengonfigurasi#Header Toolbar]]
4. Konfirmasi penghapusan Elemen dengan klik [[^button|Remove]]

>**warning** Dampak penghapusan Widget
> Menghapus Widget akan menghapus semua konfigurasi yang sudah dibuat.
