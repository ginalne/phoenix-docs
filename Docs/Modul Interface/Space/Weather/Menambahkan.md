# Menambahkan Weather

1. Buka halaman kerja Space
2. Klik kanan pada [[#Antarmuka Space|Outliner]] ➜ [[^field/add|Add Weather]]
3. Isi [[^field|Name]], [[^field|Description]], [[^field|Priority]], [[^field|Type]], dan [[^field|Status]]
4. Isi properti sesuai [[^field|Type]] (lihat [[Docs/Modul Interface/Space/Weather/Pengenalan#Type Weather]]) dengan nilai langsung atau [[Docs/Tipe Data/Query|Query]], dipilih lewat *toggle* pada field nilainya
