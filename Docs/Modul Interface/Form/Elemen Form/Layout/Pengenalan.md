# Elemen Layout

Elemen Layout adalah kategori dari [[Docs/Modul Interface/Form/Elemen Form/Pengenalan|Elemen Form]] yang berfungsi sebagai templat. Elemen Layout adalah satu-satunya kategori yang memiliki *field* [[^field|Type something here to add...]], yaitu tempat Anda menambahkan Elemen lain ke dalamnya. Dengan begitu, Layout mengatur tata letak, sedangkan isinya diisi oleh Elemen lain.

Anda dapat menggunakan elemen ini untuk memetakan [[Docs/Tipe Data/Table]] pada setiap kolom isian. Cukup pilih [[Docs/Tipe Data/Table]] pada Elemen Layout, lalu Elemen Input di dalamnya tinggal memilih [[Docs/Tipe Data/Column]]. Untuk data yang berelasi, elemen ini dapat disusun bertingkat dengan memakai pivot.

Kategori ini memiliki elemen sebagai berikut:

 1. [[Docs/Modul Interface/Form/Elemen Form/Layout/Card]]
 2. [[Docs/Modul Interface/Form/Elemen Form/Layout/Full]]
 3. [[Docs/Modul Interface/Form/Elemen Form/Layout/Split]]
 4. [[Docs/Modul Interface/Form/Elemen Form/Layout/Accordion]]
