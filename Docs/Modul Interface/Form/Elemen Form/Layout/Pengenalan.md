## Elemen Layout

Elemen Layout berfungsi sebagai templat. Elemen Layout adalah satu-satunya kategori yang memiliki *field* [[^field|Type something here to add...]], yaitu tempat Anda menambahkan Elemen lain ke dalamnya. Dengan begitu, Layout mengatur tata letak, sedangkan isinya diisi oleh Elemen Display dan Elemen Input.
