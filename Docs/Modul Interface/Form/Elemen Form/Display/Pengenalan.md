# Elemen Display

Kategori dari [[Docs/Modul Interface/Form/Elemen Form/Pengenalan|Elemen]] yang berfungsi menampilkan informasi. Informasi yang ditampilkan dapat berupa isi statis (misalnya judul atau keterangan), atau hasil dari [[Docs/Tipe Data/Expression]] terhadap nilai [[Docs/Modul Interface/Form/Binding]] (misalnya nilai total).

## Macam-macam Elemen

Kategori ini memiliki elemen sebagai berikut:

2. [[Docs/Modul Interface/Form/Elemen Form/Display/Table|Table]]
3. [[Docs/Modul Interface/Form/Display/Tooltip/Penjelasan|Tooltip]]
4. [[Docs/Modul Interface/Form/Display/Qr/Penjelasan|Qr]]
