# Format Data : Icon

Format dalam [[Docs/Tipe Data/File]] untuk menyimpan data bersifat ikon. Berikut adalah batasan ekstensi atau _mime type_ yang dapat diupload:
1. Wajib bersifat _image_ seperti *.ico, *.svg, *.png dan lain-lain.
2. _Mime type_ yang digunakan dimulai dengan prefix “_image/_”.
