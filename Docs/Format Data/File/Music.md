# Format Data : Music

Music adalah [[Docs/Format Data/Pengenalan|Format Data]] dalam tipe data [[Docs/Tipe Data/File]] untuk menyimpan data bersifat audio. Berikut adalah batasan ekstensi atau _mime type_ yang dapat diupload:

1. Wajib bersifat _image_ seperti *.mp3, *.ogg, *.wav dan lain-lain.
2. _Mime type_ yang digunakan dimulai dengan prefix “_audio/_”.
