# Format Data : Video

Format dalam [[Docs/Tipe Data/File]] untuk menyimpan data bersifat video. Berikut adalah batasan ekstensi atau _mime type_ yang dapat diupload:
1. Wajib bersifat _image_ seperti *.mp4, *.m4a, *.mkv, *.mpeg dan lain-lain.
2. _Mime type_ yang digunakan dimulai dengan prefix “_video/_”.
