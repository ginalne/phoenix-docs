# Format Data : Media

Format dalam [[Docs/Tipe Data/File]] untuk menyimpan data bersifat media. Berikut adalah batasan ekstensi atau _mime type_ yang dapat diupload:
1. Wajib bersifat media seperti *.png, *.mp4, *.mp3, *.webp dan lain-lain.
2. _Mime type_ yang digunakan dimulai dengan prefix “_video/_”, “_image/_”, “_audio/_”.
