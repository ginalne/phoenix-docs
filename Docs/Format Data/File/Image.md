# Format Data : Image

Image adalah [[Docs/Format Data/Pengenalan|Format Data]] dalam tipe data [[Docs/Tipe Data/File]] untuk menyimpan data bersifat gambar atau citra. Berikut adalah batasan ekstensi atau _mime type_ yang dapat diupload:

1. Wajib bersifat _image_ seperti *.png, *.jpg, *.webp, *.jpeg dan lain-lain.
2. _Mime type_ yang digunakan dimulai dengan prefix “_image/_”.
