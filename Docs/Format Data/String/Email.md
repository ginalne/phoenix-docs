# Format Data : Email

Email adalah [[Docs/Format Data/Pengenalan|Format Data]] dalam tipe data [[Docs/Tipe Data/String]] yang memberikan pengalaman input yang aman untuk pengisian alamat email, karena secara default pengisi harus dengan benar memasukan sesuai dengan format email yaitu name@somedomain.
