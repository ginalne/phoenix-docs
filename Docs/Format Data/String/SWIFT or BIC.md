# Format Data : SWIFT/BIC

SWIFT/BIC adalah [[Docs/Format Data/Pengenalan|Format Data]] dalam tipe data [[Docs/Tipe Data/String]] untuk menyimpan kode identifikasi unik berstandar internasional (ISO 9362) yang digunakan untuk mengidentifikasi bank atau lembaga keuangan saat melakukan transfer uang antarnegara (internasional).
