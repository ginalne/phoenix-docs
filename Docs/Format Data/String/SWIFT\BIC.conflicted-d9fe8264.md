# Format Data : SWIFT/BIC
Format dalam [[Docs/Tipe Data/String]] untuk menyimpan kode identifikasi unik berstandar internasional (ISO 9362) yang digunakan untuk mengidentifikasi bank atau lembaga keuangan saat melakukan transfer uang antarnegara (internasional).
