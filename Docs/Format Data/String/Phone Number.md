# Format Data : Phone Number

Phone Number adalah [[Docs/Format Data/Pengenalan|Format Data]] dalam tipe data [[Docs/Tipe Data/String]] yang memberikan pengalaman input yang aman untuk pengisian nomor telepon, karena secara default pengisi harus dengan benar memasukan nomor telepon sesuai dengan format internasional, yaitu kode negara serta simbol pemisah yang mempermudah penginputan nomor telepon.
