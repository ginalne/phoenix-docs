# Format Data : Short Text

Short Text adalah [[Docs/Format Data/Pengenalan|Format Data]] dalam tipe data [[Docs/Tipe Data/String]] secara _default_ yang tidak memberikan pemformatan apapun.

Anda dapat menggunakan format ini untuk pengisian bersifat teks pendek yang tidak memerlukan bantuan format khusus.
