# Format Data : Slug
format dalam [[Docs/Tipe Data/String]] yang memberikan pengalaman input yang aman untuk pemformatan Slug, yaitu teks yang tidak memiliki simbol yang bagian dari alamat URL website yang terletak di bagian paling belakang setelah nama domain, ditulis menggunakan huruf kecil, dan dipisahkan dengan tanda hubung atau tanda minus (`-`) alih-alih menggunakan spasi.
