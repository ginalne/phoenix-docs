# Format Data : Mobile Number

Mobile Number adalah [[Docs/Format Data/Pengenalan|Format Data]] dalam tipe data [[Docs/Tipe Data/String]] yang memberikan pengalaman input yang aman untuk pengisian nomor handphone, karena secara default pengisi harus dengan benar memasukan nomor handphone sesuai dengan format internasional, yaitu kode negara serta simbol pemisah yang mempermudah penginputan nomor handphone.
