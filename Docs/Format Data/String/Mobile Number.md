# Format Data : Mobile Number
format dalam [[Docs/Tipe Data/String]] yang memberikan pengalaman input yang aman untuk pengisian nomor handphone, karena secara default pengisi harus dengan benar memasukan nomor handphone sesuai dengan format internasional, yaitu kode negara serta simbol pemisah yang mempermudah penginputan nomor handphone.
