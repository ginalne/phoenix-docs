# Format Data : Username
format dalam [[Docs/Tipe Data/String]] yang memberikan pengalaman input yang aman untuk pengisian username, yaitu format yang tidak boleh memiliki huruf besar, diawali dengan angka dan memiliki simbol tertentu. Format ini cukup familiar digunakan oleh website atau sosial media sebagai username.
