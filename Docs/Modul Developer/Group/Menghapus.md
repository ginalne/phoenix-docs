# Menghapus Group

1. Pindahkan seluruh User di Group tersebut dan di Group anaknya ke Group lain. Lihat [[#Memindahkan User]]
2. Buka folder yang berisi Group di [[Docs/Dasar/Antarmuka#Area Manajemen Folder]]
3. Klik kanan Group ➜ [[^button/delete|Delete]]
4. Konfirmasi dengan klik [[^button|Delete]]

>**warning** Dampak penghapusan Group
> Daftar Workspace pada Group tersebut hilang. Penghapusan Group juga menghapus Group anaknya. Group yang dihapus, beserta Group anaknya, tidak boleh masih memiliki User, jadi pindahkan semua User terlebih dahulu.
