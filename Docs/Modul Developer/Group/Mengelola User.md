# Mengelola User dalam Group

Saat User baru terdaftar di [[Inisialisasi/Apa itu Pro?|Pro]], sistem otomatis menempatkannya ke Group berstatus default. Pada Pro baru, Group tersebut adalah Group [[^field/group|Administrator]]. Untuk menempatkan User ke Group yang sebenarnya, pindahkan User dari Group lama ke Group tujuan.

### Memindahkan User

1. Buka halaman kerja Group
2. Klik panah di sebelah kiri judul Group agar Group asal dan Group tujuan sama-sama terlihat
3. Tekan dan tahan User pada kolom [[^field|User]] di Group asal
4. Seret ke kolom [[^field|User]] di Group tujuan, lalu lepaskan

Satu User hanya dapat berada dalam satu Group, sehingga User berpindah dari Group asal dan tidak tersalin. Setelah dipindahkan, akses User mengikuti Workspace milik Group tujuan.
