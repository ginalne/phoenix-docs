# Mengubah Group

1. Buka halaman kerja Group
2. Klik [[^button/edit|Edit]]
3. Ubah [[^field|Name]] atau [[^field|Description]]
4. Klik [[^button|Update]]

>**note** Edit pada bilah navigasi
> Tombol [[^button/edit|Edit]] pada bilah navigasi hanya mengubah [[^field|Name]] dan [[^field|Description]]. Untuk Group anak, gunakan menu [[^field/edit|Edit]] pada Group anak (lihat [[#Mengubah Group Anak]]).
